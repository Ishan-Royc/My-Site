## Darwin Neural Network
September 2026 - October 2026

Languages: TypeScript

Libraries: None

CI/CD: N/A

A Neural Network designed to mimic Darwinian evolution in its training. A batch of randomly-weighted neural networks is generated, the best few are selected, and then used to create the next batch/generation of networks. This continues for a set number of generations, although the training process can be changed to train continuously until a certain error threshold is passed (not recommended since this can take a lot of time and computing power).

I built this project using pure TypeScript, so as to have minimal dependencies. 

I aim to improve the training process further by having the program adjust the model sizes to the problem (e.g. if it sees that models with fewer layers but more nodes per layer, or more layers with fewer nodes, etc. are better at solving the given problem, it will favor them more).

October 2026 - Present

Languages: TypeScript, TSX, HTML, CSS, MarkDown

Libraries: ReactJS, React-Markdown, React Router, Vite, Motion, Tailwind CSS

CI/CD: Cloudflare Workers

My portfolio website, which you’re currently browsing, is a central place to explore my projects and learn more about my background. It highlights projects I’ve built and contributed to, along with my education, work experience, research, skills, and ways to get in touch. 

I built the site with React and TypeScript, using React Router for navigation, React Markdown to render content, and Motion for interactive effects. Vite powers the development setup, and the site is deployed with Cloudflare Workers. My use of markdown keeps the TSX much shorter and readable, as the content is all kept outside in separate `.md` files and rendered when the user loads the page.
